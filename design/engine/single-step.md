Decision: The engine has a single-step mode beside running freely and dispatching nothing, switched while `run` runs and shown in the engine state the interface reports: in it the engine runs exactly one round (an agent's round, a step of the engine's own, a run of a tool cell, or starting a work counts as one) and runs the next only when the owner asks for it through the interface, instead of `run --once`, which takes a whole pass and can run several rounds, because whenever the engine is being debugged it runs only in single-step mode: one round, then what it was given and what it returned are looked at, then the next.
