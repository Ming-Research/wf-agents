- A running work can be stopped and started over by taking over: a new work takes its branch, working directory and pull
  request, walks from the first cell, and is told what exists and the rulings before. What was made is not wasted.
  Clearing everything would lose the old work, and if really needed the new work can rewrite it.

- Before an item is created the engine mechanically looks among open items, those just opened included, for similar
  ones, and hands them to the architect to judge whether to put it in one or really open another. That step is
  mechanical and should not rest on the architect remembering.

- Test results are filled in by the engine from the JUnit artifacts CI uploads, with the project's configuration naming
  the artifact and the test name's separators, not reported by the agent; other projects can join with little adapting.
  An agent misreading results runs more, and when one unit does not compile the other tests have no results.

- A work that changes one of the engine's checks of returns is judged, until it is installed, by the check as it was,
  and its own returns can be sent back by the very fault it mends. So it names each check it changes, with why the
  installed check would send a right return back; what only those checks find is set aside and not sent back, while the
  installed checks still run on every return; each finding set aside is judged by a review, the declaration is checked
  against the diff, and none reaches the merge unjudged. Only the project the engine is built from can declare. Such a
  work once went around the check by asking the advisor, at seven more rounds against two. Splitting the change to the
  check into an item merged and installed first costs an item, a whole graph and an installation each time, and cannot
  split a work whose change is the check itself. Running the checks in CI cannot work, since a check reads the live
  database, the worktree and the configuration.

- A check of an agent's return reports every problem it can find in that return at once, because each send-back costs a
  round. It returns early only when a later test presupposes that an earlier one holds.
