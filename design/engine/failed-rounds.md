Decision: Whatever the engine pauses a work for (a prompt too long, returns sent back too often, a step it cannot take, such as its own tool cell's return that does not fit the flow), it tells the owner once, the pause is the engine's, which the owner's Start all leaves until the owner starts that work on its own, and it closes the round the pause left open with the reason, as a run that ended without a return, so the round shows as what it was and the cell runs again as a new round once the owner lets the work go on; a round an earlier engine left open when it paused is closed the same way, with the reason the work was paused, when the work goes on; instead of a paused work the owner hears nothing of and a round shown as running for ever, because a pause waits for the owner, and the owner can only act on what the owner is told.

Rejected:
