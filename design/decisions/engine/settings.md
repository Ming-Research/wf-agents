# Settings

The settings of the installation and of each project, as the texts sent to the agents name them.

### decision a-text-names-a-setting-by-its-key
A text sent to an agent names a setting by its key between backticks and is given its value beside the name; a flow whose texts name one with no value is refused as the engine starts.
- rejected: an agent proposed a slot of its own for each setting in the texts, filled in by code one by one; the owner rejected it, because the old system named `owner.language` and gave its value beside the name, one way for every setting.

### decision how-tests-are-named-is-a-project-setting
How an agent names a test to `run_tests` is the project's setting `project.test_names`, which the tool's words name; the project's guide says nothing of the engine's tools.
- replaced: The project's guide telling the engine's agents how to name tests to the engine's checks stood on main; the owner changed it, because the guide holds what is the project's, and is not to be coupled to the engine.
