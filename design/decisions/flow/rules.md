# The rules every agent is given

The general and the engineering rules the flow gives every agent, beside its cell's task.

### decision the-old-rules-came-back
Every agent is given the old system's general and engineering rules, brought back as they were and changed only where the new design forces it.
- replaced: The rebuild's own words for agents, written with none of the old rules, stood on main; the owner changed it, because those rules held much of value settled over a long time, the basic rules for code among them.

### decision the-rules-name-no-block-to-ask-in
Where the rules send an agent to the owner or to something it must wait for, they name no block: it asks the owner, or says it cannot ask, and gives what it waits for to the engine in its return.
- replaced: Rules telling an agent to ask the owner in `questions` stood on main; the owner changed it, because the cells of the review lines cannot ask, and the rules tell how agents work, not the flow.
- replaced: The rule that what must be waited for goes in the return as a tool or a question stood on main; the owner changed it, because the review lines cannot ask, and each cell learns from its own words how to ask for what it waits for.

### decision a-comment-says-only-what-bears-on-the-code
A comment an agent writes in code says only what bears on the code beside it, never its standing in a process, and one that does is reported in `observations`.
- rejected: an agent proposed a rule saying at length what a comment holds and leaves out; the owner rejected it, because it was too long.
- rejected: an agent proposed that a comment never say the code's history; the owner rejected it, because history may be written.

### decision nothing-is-kept-in-the-command-lines-memory
The rules tell an agent to keep nothing in the command line's own memory, and say nothing of where what must last goes.
- replaced: The rule's second half, that what must last goes into the round's return, stood on main; the owner changed it, because a fork showed the first reading take what it read for what must last and put it into a block made for something else.

### decision the-agents-choose-the-language-they-pass
Agents choose the language of the texts they pass to each other; only the title, written into the repository, and the plan for the owner keep a language set.
- replaced: Blocks telling the agent to write in English stood on main; the owner changed it, because the language of what agents pass to each other is theirs to choose.
