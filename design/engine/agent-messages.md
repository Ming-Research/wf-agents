Decision: An agent round's inputs are of two kinds, always and conditional: the always inputs (the cell's task, the addresses of the conditional inputs to work from under the number of each of the cell's inputs, why the round happens and which format to hand in) are given every time the cell is entered, even word for word as the last time, while each conditional input (rules, the item, settings, the project's design goal, the repository guide, other cells' and engine steps' outputs, tool results, replies, interjections, return formats, what each numbered input is, the worktree) is given when the session does not hold it and referred to by its address when it does, because the always inputs steer the round, while a conditional input repeated to a session that holds it spends its context and hides what is new.

Decision: After a return sent back, the message says only why it was sent back and that the return is to be rewritten, with its format's address, and gives and refers to nothing else, instead of the whole message again, because the agent did the work and holds everything it was given; only the return was wrong, and giving the task again tells it to do the work again.

Decision: What each of a cell's inputs is, as the flow describes it, is the conditional input `inputs:<cell>`, given once in a session for each flow version, and the always inputs list only each input's number with its addresses, instead of each input's description beside its addresses every round, because the descriptions do not change within a flow version and were most of the always inputs.

Decision: The inputs every agent's cell has (the project's design goal, the results of the tools asked for, the interjections) go by a name the flow gives them, are described once in `format:common`, and each cell's `inputs:<cell>` names them by their number only, instead of every cell's list describing them again, because the same long descriptions were repeated at each new cell of a session.

Decision: The project guide (the project's AGENTS.md, the index of its design tree and the nodes the item cites) is an input every agent's cell has, given once in a session and referred to after, and a message gives the project's own context, its guide and its settings such as its design goal, before anything else it gives, instead of the guide given to the research round only and the project's context after the formats and the rules, because the review, the adversarial tester, the advisor and a session started afresh read no project instructions of their own, and the project is what every other input is read against.

Decision: The project guide is read with git from main as the work's branch has merged it, the merge base of the branch's head and the fetched main, instead of from the worktree's files, because the work's own edits to its design tree made the guide a new one and gave it whole again (work 9's engineer was given its 14,730 characters a second time in R9-12, after adding a node on its branch, 85% of that message), while an agent knows what it edited itself.

Decision: When an input of the standard context, what every agent needs once in a session (a return format, a list of inputs, a rule, a project setting, the worktree, the project guide), changed since the version a session holds, the session is given only what changed, under the input's address (for the guide, its new version's own), naming the version it changes and the round the session got it in: the lines of a text that differ, as a unified diff, or the entries of an object that differ, null for one no longer there; each round's record keeps the whole version of each such input in `contents` and names its key, so that a later round reads the version its session holds, instead of the new version whole, because the standard context is the largest part of a session's first message, while a changed rule, setting or node of the guide is a few lines of it.

Decision: Before a message is sent, the engine checks every conditional input it would give whole: content the session already holds, under any address, or a whole new version of an input of the standard context the session holds an earlier version of, stops the message, and the engine sends nothing, pauses the work with a reason that names the input's address, its size and the round the session got it or its earlier version in, and tells the owner; a value new at its place (another round's return, what the engine reports of the work as it is now, a row of the database that is its own thing such as an interjection), a word two places give alike, and anything given to a session that holds nothing (one started afresh or just compacted) pass, instead of fixed limits on the size of an input or a message, because a fixed size misses small repeats and stops large inputs that are right, while giving a session again what it holds is the fault itself: over the recorded rounds of works 5 to 9 the check catches exactly the four times work 9's sessions were given the project guide again.

Decision: What already exists for the item says the branch and the pull request the work took over as its start cell took them over, instead of the branch and pull request the work has now, because the pull request the work opens itself would make it a new input given again in full and would call that pull request one the work took over.

Decision: A cell with no task of its own is sent no Task heading, instead of an empty one, because an empty heading tells the agent there is a task it was not given.

Decision: The value of each setting a rule or a return format names is written beside its name where it is named, and the work's worktree, branch and main are the conditional input `work:<id>`, instead of a conditional input for each setting and the worktree's sentences in every round, because a setting is read with what names it, a heading for each short value cost more than the value, and the worktree does not change within a work.

Decision: A conditional input that is not a text is written as compact JSON, with no fences and no indentation, and the return formats write their schemas without `additionalProperties: false`, saying once that no object holds fields it does not list, and give each large part a schema repeats once, under `$defs`, referred to by `$ref` where it repeats (the kinds of ask, the same under each role an agent may ask, were a third of the shared forms three times over), because the headings already delimit each input, and the indentation, the repeated keyword and the repeated parts spent tokens on nothing the agent needs.

Decision: A part several cells' own answers hold alike that the flow's returns name as given once (`once`: the architect's `effects`) is given in `format:common` under `$defs`, to the sessions of the lines whose cells hold it, and each of those cells' formats refers to it there, instead of whole in each cell's format, because a session that goes through those cells took the same schema in again at each (the effects were 15K characters in the formats of eight cells; format:H1 went from 15,795 characters to 979), and the flow names the parts so that a line or a cell that does not hold one is not given it for nothing.

Decision: Whether a session holds a conditional input is decided by the session manager as the engine builds the message, from the record of what that session was given and handed back since its last compaction (in a round, or in a keep-warm ping while it waited), by content: an input identical to one it was given or to a value of its own returns is held, and after a compaction it holds nothing, instead of the compiler working out statically which inputs a session holds, because a static answer has to hold on every way to a cell, so loops and resumed cells were given the same values again, values read through the database were never held even when the session wrote them, and an input taken as held vanished from the prompt with no pointer to it.

Decision: Every conditional input is given under the one rule, wherever it comes from: when the session does not hold it, as in a new session, one started afresh when its context grew full, or another line's session, it is given, and when it does, it is referred to by its address; a conditional input with nothing in it is not written at all, and the list of inputs to work from says `none` for a cell's own input that has nothing, while one every agent's cell may have (tool results, the owner's answer) is listed only when it has something, because a session needs each thing once, whenever it does not have it, a rule that depends on where an input comes from or on the start of a session fails as soon as a session is started afresh midway, and an agent cannot tell an input of its own that has nothing from one that is missing.

Decision: A value a round produced is addressed by the round's name, R<work>-<n>, the cell and the field path as the flow writes it, joined by middle dots, such as R5-39 (round 39 of work 5), cell 4, end.test_changes[added], its version being the round; every message starts with its own round's address, so an agent's own return sits in its context under that heading; the other conditional inputs are rule:, config:, item:, design_card:, ask: (an ask of the owner), ij: (an interjection), image: (an image the owner sent) and work: with a name or id, format:common, and format: and inputs: with a cell, and what the engine computes carries the round it computed it for; identical content is one conditional input, addressed by the earliest round that produced it, and the always inputs name a concrete address, never the latest of anything, instead of inputs named by descriptions written for people, because an address points to one version the agent can find in its context.

Decision: The work's history is given to no cell; a cell called in from another line is given the outputs of the engineer's line it needs as named inputs, and an engine step's output reaches agents only as a conditional input of the cells the flow says read it, instead of the history, because the history re-sent every round's whole record each round, descriptions written for people included, and carried engine steps' inputs, which never belong in an agent's context.

Decision: The images the owner sends with words reach an agent only with the owner's words, wherever those are given: what was said to a line (an interjection, its own images or those of the owner's words its matter holds), an architect's matter of the owner's words, the owner's answer to an ask or to the architect's question, the owner's reply in a work's group to a question the architect held, and what was said in the groups of a project's works. Decision: The index of the database (each table and view with its columns' names, whole, and the first sentence of what it holds, read whole however many comment lines it takes and cut at a word to 80 characters with an ellipsis) and the query that reads one in full are in the query tool's description, which the compiler writes from `db/schema.sql`, so they come with the return formats once in a session, instead of a conditional input of their own, the whole schema with its comments, the first comment line, which cut a sentence in half wherever the line ended, each first sentence whole, which made the index 13,127 of the 17,143 characters the common forms took in a new architect session's first round, or the index without the columns, with which the architect guessed columns in its first queries and lost them, because an agent reads them where it learns to ask for the tool, the start of a sentence tells which table to read while a column guessed wrong costs a round, a round reads a few tables, and a definition with its comments is one query away.

Decision: The forms every agent's return shares (asking, tools, pausing, answers, redirect, side reports, progress) are one conditional input holding every tool and role some cell of the session's line has, the same for every round of the line, and each cell's own answer is another, which also says which shared forms the cell has; both are given once in a session for each flow version, with the value of each setting they name (such as the owner's language) written beside it, and the always inputs name the format to hand in, while the command line keeps its one structured-output envelope and the engine checks each return against the cell's whole schema, instead of each cell's whole return schema in every round, because the shared forms are most of every schema and do not change within a flow version.

Rejected:
- Working out at compile time which inputs a session already holds: rejected because a static answer must hold on every way to a cell, so it is too conservative for loops and resumed cells, cannot see what was read through the database, and drops a held input from the prompt without saying where it is, while the record of each session says exactly what it was given.
- Giving the work's history to the cells called in from other lines: rejected because it repeats every round's whole record in every round instead of the outputs a cell needs, and puts engine steps' inputs in an agent's context.
- One address for each source an input reads, such as the database view the acceptance is read through: rejected because one content then has several addresses, and a session that wrote a value is given it again under another name.
- Giving a conditional input by where it comes from (written by the session's own line, needed from the start, from outside): rejected because a session started afresh midway, or another line's session, holds none of them, so each is given by whether the session holds it, whatever its origin.
- Giving the whole message again after a return sent back, with the reason added: rejected because it repeats the task to an agent that did it, and spends a round's worth of tokens to say that one return was written wrongly.
- Fixed limits on the size of one input, of the inputs a round gives and of a whole message: rejected because a fixed size misses a small repeat and stops a large input that is right; the largest ordinary inputs of works 5 to 9 were 11,328 characters for one input (a round's tool results) and 39,698 for the inputs of one round (a first review), while the project guide given again was 14,727.
