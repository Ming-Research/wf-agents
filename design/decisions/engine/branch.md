# What the engine reads of a work's branch

What the engine reads from a work's branch, and to whom it attributes what it reads.

### decision a-version-read-at-a-rounds-end-is-that-rounds
A round of a line that may change the work hands in what it committed when it ends its cell's work, not when it asks for calls; a read that writes from outside leaves the head while its cell waits.
- rejected: an agent proposed writing every new head read from the branch as coming from outside; the owner rejected it, because a tester's commit would then set the review's limit on going round back to zero.
- replaced: Handing in what a round committed at the end of every round of such a line, one that asks for calls included, was on main; the owner changed it, because the code review ran on a branch whose tests had not come back yet.
- rejected: an agent proposed handing it in as it was, and holding that version from the other cells in the walk until the cell's calls ended; the owner rejected it, because the walk would need one more rule, for a version written and not yet new to the other cells.
