# The flow

What every flow's definition holds, whichever flow it is.

### decision every-agent-takes-is-the-flows
What every agent cell of a flow watches and reads beside what its own file names, such as every cell's questions and
words, is named once in the flow's `flow.toml` (`[every_agent]`), each with its kind, and given each agent cell first; a
datum a cell names itself it takes as its own file names it. The engine holds no list of it, and no cell's file repeats
it.
Why: What every cell takes is part of the flow, which the owner reads in its files and on its chart (Article 7); written
in each cell's file it would be one thing in many places, and held in the engine's code, one the flow does not show
(principle one-thing-one-place).

### decision a-datum-of-a-cell-s-own-is-made-where-a-cell-names-it
A datum each cell or each line has its own of, such as a cell's questions, is made from its file beside the flows only
for a cell or a line whose name a cell names it by, among what that cell watches, reads or writes; `{each}_` in what
every agent cell takes stands for those made.
Why: Made for every cell, a cell that may not ask would have questions of its own that no cell writes and that run
nothing, each a block with no writer (principle every-field-has-a-reader).

### decision the-card-is-the-flows
What the item's card shows the owner of a work is named by the work's flow (`card` in its `flow.toml`), data of the
flow in their order; the page draws a section of each by its name, and names no datum and no flow of its own.
Why: The page told one flow by its name and read three blocks by theirs, which held for those two flows alone and
would have broken without a word when a flow renamed one (principle engine-knows-no-cell).
