### decision meaning-told-by-the-writer
A choice changes its meaning when its value does, whoever writes it; prose a person writes always changes its meaning, and what the outside writes does unless it says it does not. Of prose a cell writes, the cell says with each write whether the change matters to the cells that read the block, compared with the version at which its meaning last changed, which it is told; a cell that says it does not matter is not taken at its word where the meaning changed after its run started, so that it never saw what it wrote over.
Why: An agent never writes the same text twice, so judging prose by its text would run every later cell again after every rerun, and comparing with the version at which the meaning last changed keeps a row of small changes, each said not to matter, from adding up unseen (Article 3). A second agent to check the answer was turned down because it costs a round at every change, and a count that goes up at each change of meaning because it would leave to whoever does the counting which version a write is compared with.
