# The design tree on a work's branch

When the design tree on a work's branch has a new version, and what a version holds.

### decision the-tree-is-a-new-version-where-its-id-differs
The design tree on a work's branch has a new version where its git tree differs from the last version's, whoever changed it: main in what it brought in, or the work in a commit of its own.
- replaced: The tree counting as main has it, renewed only as main is merged into the work, stood on main; the owner changed it, because an input has changed when its content has, whether on main or in the work.
