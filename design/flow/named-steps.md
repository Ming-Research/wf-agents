Decision: Everything the engine carries out has a name in the flow (each action, check and step done every time, besides the engine's own steps), with its prose kept as the description, and the engine has exactly one implementation per name; the compiler checks both ways, that every name used is implemented and every implementation is used, instead of the engine reading the prose, because prose cannot be checked and two readings of it drift.

Decision: An input read from the database names the table or view it reads, and the compiler loads `db/schema.sql` into an in-memory database to check that each one exists, because an input whose source is missing must fail when the flow is compiled, not when a work reaches the cell.

Decision: Rows on the main path are flagged in the flow, and the compiled flow carries the flags, because the anomaly view counts every transition off the main path without agents reporting it.

Decision: Each cell has a short English name, its own within its graph, and a cell that does the same in both graphs has the same name in both (`tools`, `ask.owner`); a cell of a stage of several cells has its stage before a dot (`test.fix`, `policy.correct`), a cell that is a stage on its own one word (`implement`), and each stage, and the chart's box for it, the same short word, as the asking part `ask`, instead of a number or a code by its place, or a name alone, because a number says nothing of what its cell does, the two graphs numbered alike cells apart, adding or removing a cell left the numbers uneven, and a name alone does not say which part of the flow its cell is in, as P1 at least said policy; a work and its rounds keep the ids of the flow version the work ran on, so a reader of the works and rounds of every version names a cell by every id it has had: its number or code, its name before it took its stage, and its name now.

Decision: A text of the flow names a cell by the word cell and its name in backticks, or several after the word cells (cell `ask.way_on`, cells `test.full_ci`, `merge.queue` and `watch_main`), and the compiler refuses a text that names a cell its graph does not have, or, for a text every graph shares, that no graph has, saying where the text is and what it names, instead of cells named in prose as they come, because a renamed or removed cell otherwise leaves a text that points nowhere, which only a reader finds, and a field in backticks alone cannot be told from a cell.
