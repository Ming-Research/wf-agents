Decision cut-off-resume: When the engine crashed or was stopped and starts again, or is updated without a change to the flow, the same work goes on, on the same flow version, at the same cell, in the same session: the round that was running is recorded as cut off, and the next round's message says only that it was cut off midway and that the agent first looks at the worktree as it is now (the files changed, the commits made) before going on, instead of the whole message again, because the session holds everything the cut-off round was given, and only what happened in the worktree since is unknown.

Decision version-move: When the flow moves to a new version, a work on an older one moves to it when it next goes on (the owner continues it, steps it, or starts all works), if the cell it stands at is unchanged there and every return it handed in still fits its cell there: the same work goes on at the same cell in the same sessions, which are given what the new version changed of what they hold as any changed input is given (a changed command line only writes their cache again), and the work records the version it moved from, which the page shows on it as "moved to version N". The cell is unchanged when the new version has a cell of the same id, kind and line, whose inputs have the same names and sources and whose rows the same names, conditions and targets, in the same order, and the cells the work goes back to from the asking part (the cell it left, the cells waiting for an answer) are still cells of the same kind; a return still fits when the new version has its cell and the cell's schema there, as the work's project's agents are asked it, takes the return as its round stored it, whatever the schema's texts say, as it does when the version added a field the return may leave out or a value a field may take; the work is taken over, saying the round and where its return does not fit, only when the version took out or renamed a field a return holds, required one it lacks, or no longer allows a value it holds. A return is what the cell's schema in the work's own version takes: what the engine records of a row it took itself, holding no return (an ask withdrawn, a turn waited for in the merge queue, a session begun afresh), is none, and the new version reads it as the old one did. Every return the work handed in counts, not only those the cells it can still reach name among their inputs, because every agent's cell reads the cell it came from, which may fall back on any cell the work ran, and the engine's own steps and views read returns by their cell beyond what the inputs declare, so that no earlier return is sure not to be read again; a return the new version's schema takes is one its readers can read. Instead of every work on an older version taken over, because most changes to the flow leave the cell a work stands at and its returns as they were, and a takeover throws away its sessions and its rounds and starts it again from the first cell; and instead of a return's cell having to keep the same shape, field for field, because in the sixth trial the fields the named tests' results added to the returns of the tools' cell `X1` took over a running work whose returns of `X1`, all from other tools, the new schema took as they were: a compatible addition must not throw away hours of work. This applies to the engineer's works and the architect's alike.

Decision takeover-on-go-on: A work on an older flow version that cannot move is taken over when it next goes on, not when the engine starts: it stops, saying why and what of the new version kept it from moving (the round it was in is cut off, its design cards are replaced and its asks of the owner that are still unanswered need no answer), and its item gets a new work on the new version from cell `S1`; the old work ends at cell `C1`, from the cell it stood at, which it keeps as where it stopped, with new sessions, before any item from the queue; until then the owner still rules on its design cards and answers its asks on the page, and the new work is given those rulings and answers as it is given everything earlier works left, and the page says on such a work that it is on an older flow version, and moves or is taken over when it goes on. Decision takeover-slots: A new work that takes over takes a slot only when one is free, as every work does: those that find a free slot start at once, in the order of the works they replace, and the items of the rest wait at the head of the queue, ahead of the items queued before, in the same order, and start as slots free, instead of starting every one at once, because a machine's slots say how many works it holds, and a change of flow does not give it more.

Decision start-over: The owner, with Start over in a work's group, and a project's architect, with the effect `start_work_over` naming the item and why, start a work on an item over: the engine takes it over as it takes over a work on an older flow version that cannot move, by the same code (`Engine::take_over`), the work's end and the group's notice saying who started it over and, for the architect, why; the new work is on the flow version the engine runs, takes over from cell `S1` the branch, the worktree with what is not committed in it, and the pull request, is told at `R1` what exists, the owner's rulings and answers and the questions withdrawn included, is paused as the owner had paused the old one, takes a slot as any takeover does, and goes on under the owner's Start of the old one while every work is paused. The request is an action of the outbox (`start_over`), written in the asker's transaction, which the engine carries out before any other step of that work and at each turn of its loop, whatever the global state, since it runs no agent and does nothing outside the database; a round of the work that runs when it is asked hands in nothing, what it cost kept on it, and the takeover cuts it off once its agent's process has ended, since the engine cannot stop that process. A work of the architect cannot be started over, nor one ended or at its end, and the owner's and the architect's requests are refused alike.
