Decision: An input read from the database names the table or view it reads, and the compiler loads `db/schema.sql` into an in-memory database to check that each one exists, because an input whose source is missing must fail when the flow is compiled, not when a work reaches the cell.

Decision: Rows on the main path are flagged in the flow, and the compiled flow carries the flags, because the anomaly view counts every transition off the main path without agents reporting it.

Decision: Each cell's id is a code, its stage's letter and its order in the stage (`S0`, `T6`, `P10`), and its title, which says in words what it does, is shown beside the code on the chart and the page; each stage keeps its short word and the chart's box for it shows the letter as well (`Stage T: test`), the asking part's being `A`, the helpers' `X` (the tools `X1`, the search `X2`, waiting for the owner's Start after a pause `X3`, handing on an agent's answers to who interjected `X4`), the end of a work cancelled or taken over, at the stage `cancelled`, `C1`, and the architect's wrap-up and the end of its work, two stages, both `E`; a cell that does the same in both graphs has the same code and title in both (`A3` "Owner answers", the ask of the owner, and `X1`, the tools), instead of a number by its place, or a name, because a number says nothing of what its cell does and adding or removing a cell left the numbers uneven, and a name, even with its stage before it, was longer to type and to find than a code whose letter says which part of the flow its cell is in; a work and its rounds keep the ids of the flow version the work ran on, so a reader of the works and rounds of every version names a cell by every id it has had, its number or first code, its name and its name with its stage, but for an id that is now another cell's code: the architect's first codes P1 to P11, N1, Q1, Q2 and X1 named other cells, and a round of those versions at one of them reads as the cell with that code now, instead of a round of this version reading as another cell.

Decision: A text of the flow names a cell by the word cell and its code in backticks, or several after the word cells (cell `A4`, cells `T2`, `M2` and `L1`), and the compiler refuses a text that names a cell its graph does not have, or, for a text every graph shares, that no graph has, saying where the text is and what it names, instead of cells named in prose as they come, because a renamed or removed cell otherwise leaves a text that points nowhere, which only a reader finds, and a field in backticks alone cannot be told from a cell.
