Decision: The engine has two modes, running (it takes every work as far as it can) and holding (it starts nothing by itself), switched while `run` runs from the engine's state in the page's bar, switching to running asked once to be confirmed; running one round is no mode but an action on a work's page, "Run next round", which the page offers only while the engine holds and that work has a next step, instead of a single-step mode that took a step of whichever work came next, because a step must be of the work the owner is looking at, and a control in the bar of every view, pressed while several works ran, stepped something the owner could not tell.

Decision: Before the owner runs a work's next round, its page shows what the round will be (the cell; an agent's round, a step of the engine, a run of tools or an ask of the owner; and the message the agent will be sent, built as the round would build it with nothing run or recorded) and says beside the button that it runs one real round on the owner's account; while the round runs, the page shows how long it has run and what the agent is doing, as its command line reports it, and when the round ends the page opens it, instead of a button with no word of what it runs, because one round is run to look at what it was given and what it returned, and both are known before and after.

Rejected:
- `run --once`, which takes a whole pass: rejected because a pass can run several rounds of several works.
- A single-step mode for the engine as a whole: rejected because which work its step took could not be told before it ran, and its control was everywhere.
