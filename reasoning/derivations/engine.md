Decision engine-mechanical: The engine follows the compiled flow mechanically: it takes the row a return selects, runs the named actions and checks, and decides nothing that needs judgment; tools only execute and never choose the route, instead of the engine or a tool judging where a work goes, because judgment belongs to the agents and the owner, whose reasons are recorded and reviewed, while the engine's steps must be predictable from the flow.

Rests on: C:flow-does

Decision one-machine: The engine and the session manager run as one process on the owner's machine, instead of across several machines; provisional, because one machine is enough to run the flow first, and several machines are reopened when the work outgrows it.

Rests on: C:product-grade, F:one-machine-enough
